# Module-1-HTML Project

## Project Description

This project contains a collection of HTML5 pages created to practice
semantic HTML, forms, accessibility, multimedia, and website structure.

The project is built using only:

- HTML5
- CSS3
- JavaScript

## Completed Tasks

### Website Pages

- Home page
- About page
- Services page
- Gallery page
- Contact page

### HTML5 Practice Pages

- Registration form with validation
- Multi-step checkout form
- Media page with video and audio
- FAQ page using details and summary
- Restaurant menu
- CV / Resume page
- Blog article page

### Accessibility Practice

Implemented:

- Skip navigation link
- Semantic HTML landmarks
- ARIA labels
- Keyboard-friendly forms
- Accessibility error examples
- Accessibility fixed version

### Validation

All HTML pages were checked using the W3C HTML Validator.

Goal:

- Zero Errors
- Zero Warnings
