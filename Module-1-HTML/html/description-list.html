HTML5 Elements Dictionary

A structured technical documentation of fifteen core HTML markup tags.

Core HTML Tag Documentation

<header>
Represents introductory content or a set of navigational links for its nearest ancestor sectioning element or page root.
<nav>
Defines a section of a page whose purpose is to provide navigation links, either within the current document or to other documents.
<main>
Specifies the dominant, central content unique to the body of a document. A page must not contain more than one visible main element.
<article>
Represents a self-contained composition in a document that is intended to be independently reusable or distributable (e.g., blog posts, news stories).
<section>
Represents a generic standalone section of a document that lacks a more specific semantic element to represent it, typically featuring a heading.
<aside>
Represents a portion of a document whose content is only indirectly related to the document's main content (e.g., sidebars, callout boxes).
<footer>
Represents a footer for its nearest sectioning content or sectioning root, usually containing metadata, copyright notices, or author details.
<figure>
Represents self-contained content, optionally with a caption, that is referenced as a single unit from the main flow of the document.
<figcaption>
Represents a caption or legend describing the rest of the contents of its parent figure element.
<picture>
Serves as a wrapper container containing zero or more source elements and one image element to offer alternate visual representations for different devices.
<time>
Represents a specific period in time or a precise date, enabling search engines and scripts to parse temporal information accurately via the datetime attribute.
<address>
Indicates that the enclosed HTML provides contact information for a person or people, or for an entire organization.
<blockquote>
Indicates that the enclosed text is an extended quotation from another source, typically accompanied by a citation source via the cite attribute.
<fieldset>
Used to group several controls as well as labels within a web form to establish clear semantic visual and screen-reader relationships.
<legend>
Represents a caption for the content of its parent fieldset element, clarifying the purpose of grouped form controls.
