HTML Elements Description List

<html>
Defines the root element of an HTML document.
<head>
Contains metadata such as title, styles, and links.
<title>
Sets the title shown in the browser tab.
<body>
Contains all the visible content of a web page.
<h1>
Defines the main heading of a page.
<p>
Represents a paragraph of text.
<a>
Creates a hyperlink to another page or resource.
<img>
Displays an image on the web page.
<ul>
Creates an unordered (bulleted) list.
<ol>
Creates an ordered (numbered) list.
<li>
Represents a list item inside a list.
<table>
Creates a table to display data in rows and columns.
<tr>
Defines a row inside a table.
<th>
Represents a header cell in a table.
<td>
Represents a standard data cell in a table.
